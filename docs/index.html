Once you have the files

  1. Check that they arrived whole

    Every line that md5sum -c md5sums.txt prints should end in OK. If one doesn't, download the archive again. A computer without wget can use curl -O with the same address.

  2. Start JupyterLab in your working folder

    Run this in a terminal on your VM, then open the address it prints.

    conda activate gm5cd ~/GM5_family/mdtjupyter lab

  3. Make the notebook fetch its own data

    Put your family's download commands in a %%bash cell at the top of the notebook. At 15:15 we run every notebook in a fresh folder, where nothing has been downloaded, so it has to get the reads itself.

  4. Use the course's reference and resources

    The reads cover the six regions of the course data, so the reference genome in ~/GM5_family/reference and the resource files in ~/GM5_family/resources are all you need besides the reads.

The data are for teaching. They are based on publicly available sequencing data from volunteers who consented to its open use, with changes made for this course, so they don't come from real patients.

Every family's files and README are in the GitHub repository comparativechrono/PAH-trio.
