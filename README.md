# PAH coursework trios

Exome sequencing data for the GM5 Bioinformatics course. Each folder holds one family of three, a proband with pulmonary arterial hypertension and both parents, with its own README, reads and checksums.

| Folder | Family | Used for | Resource files |
|---|---|---|---|
| `TRIO-B/` | A male proband and his parents | Coursework | In the folder |
| `TRIO-C/` | A female proband and her parents | Coursework | In the folder |
| `TRIO-D/` | A male proband and his parents | MDT simulation, Scrum team | The course's own |
| `TRIO-E/` | A male proband and his parents | MDT simulation, Kanban team | The course's own |

The data are for teaching. They are based on publicly available sequencing data from volunteers who consented to its open use, with changes made for this course, so they don't come from real patients. Use the course reference genome, `~/GM5_family/reference/GRCh38_GM5.fa`, with any family.

TRIO-B and TRIO-C cover extra regions as well as the six course regions, so use the resource files in their folders. TRIO-D and TRIO-E cover only the six course regions, so use the course's own files in `~/GM5_family/resources`.

For the MDT simulation, the [Project Jupyter page](https://comparativechrono.github.io/PAH-trio/) has a download button and the Unix commands for each team's family.
