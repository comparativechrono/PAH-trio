# PAH coursework trios

Exome sequencing data for the GM5 Bioinformatics coursework. Each folder holds one family of three, a proband with pulmonary arterial hypertension and both parents, with its own README, reads, resource files and checksums.

| Folder | Family |
|---|---|
| `TRIO-B/` | A male proband and his parents |
| `TRIO-C/` | A female proband and her parents |

The data are for teaching. They are based on publicly available sequencing data from volunteers who consented to its open use, with changes made for this coursework, so they don't come from real patients. Use the course reference genome, `~/GM5_family/reference/GRCh38_GM5.fa`, with either family, and the resource files in the family's own folder.
